# TouchDeck 产品路线（2026-08-06 定案）

> 本文档是路线的事实来源：定位、自定义边界、场景预设、版本排期。事实变化时只更新本文档；AGENTS.md 仅持指针。

## 定位

**TouchDeck = 远程 vibe coding 的触控操作台。** UU 远程解决「看得见」，TouchDeck 解决「按得着」。

差异化锚点：

- 不抢焦点的按键注入（focusable:false + Win32，按键发到之前活动的窗口）——铁律 1，技术壁垒
- 宏 + 场景感知（前台应用命中即整组切换按钮集）
- P2P 直连，无服务器按键转发，链路干净延迟低
- 触控优化的径向菜单（为 8.8 寸平板隔视频流点按调参）

目标用户：用平板/手机远程操作 PC 跑 AI CLI 的人（先从 owner 自己出发 dogfooding）。

## 自定义能力边界（2026-08-06 定案）

**边界线：声明式配置 vs 编程。能用一份 JSON 声明、且不含任何 if/when 条件判断的自定义 = 界内；超出 = 界外。** 生态位：比快捷栏可配，比 AutoHotkey 简单。

| 维度 | 界内 | 界外 |
|---|---|---|
| 按钮内容 | 图标/标签/键组合/宏/target/confirm | — |
| 宏能力 | 四型步骤（keys/text/paste/delay + times）；可加 `launch`（启动程序，不等输出不判断）——五型封顶不再扩 | 变量/分支/条件等待/循环判断 |
| 排布 | 选布局包 + 径向自动排布（数组顺序=优先级） | 自由拖拽像素级摆位 |
| 视觉 | 选主题包 + themeOverrides 令牌覆盖 | GUI 主题编辑器、图标编辑器 |
| 场景 | process/title 匹配切按钮组 | 时间/电量/网络等触发条件 |
| 触发源 | 点球/Tab/远程按键（现状） | 语音指令识别、定时任务、手势自定义 |
| 分享 | 配置导出导入（单 JSON） | 在线配置市场 |
| 外部集成 | 不做 HTTP/API；逃生舱 = launch 调 curl | 鉴权/回调/响应解析 |

检验标准（每个自定义需求过筛）：**「能不能用一份 JSON 声明表达、且不含任何 if/when 判断？」** 能→界内做；不能→界外，引导去 AHK/语音助手/定时任务软件。

## 场景预设包（正式版上线须相对成熟，共 3 个）

机制现成（`scenarios: [{name, target, layout}]`）：预设 = 内置布局包 + 默认 config 预写 scenarios 数组 + 手动场景切换入口（自动匹配失效时人能纠正）。

1. **`cli-agent`（通用 CLI：Kimi Code / Claude Code / Codex CLI）**——现有 left-dock 演进，最成熟。各家 CLI 键位趋同。待补高频缺口：`↑`（上一条输入，改提示词）、`!`（shell 前缀）、`Tab`（补全）。
2. **`kimi-web`（Kimi Code Web）**——本质约束：**按键注入只能打字发键，点不了网页按钮**（新建会话/模式切换是鼠标活）。主干 = 语音 + 文本宏 + Enter/Esc/↑↓/PageUpDown。**先做快捷键摸底**（Enter 是否直发？Esc 能否中断？输入框焦点怎么拿？）再定内容——不摸底就是瞎配。
3. **`deepseek-agent`**——占位包（复制 cli-agent 结构，target 留空正则 + 注释），发布后再填。

## dogfooding 机制（高频操作靠数据不靠猜）

- **按键频率统计**：`enqueueAction` 按按钮 id 计数落 state，控制台显示各键次数——预设留谁删谁数据说话。
- **场景痒点账**：owner 使用中发现「想按的没有/不顺手」随时丢一句，记到 docs/touchdeck-notes.md「场景痒点账」节，攒一周沉淀进预设。

## 手感验证清单（v0.4.x 执行依据）

- **本机球（鼠标）**：点球命中率、Tab 按住-松开节奏、长按拖球反馈提前量、环数精简；补「快速连点/贴边」破坏性测试。
- **远控球（UU 隔视频流点 Windows 球）**：UU 触控注入下 pointerup 可能丢（见 notes）——重点测点按误判长按、菜单收回干脆度、400ms 按下反馈在视频流延迟下是否够；可能需要「触控模式」行为参数包（更长确认窗）。
- **安卓原生球**：滑选手势、菜单贴边、P2P 延迟反馈感——配合 v0.4.0 ack 回传一起验。

## 不做清单（防发散）

- 跨端（无 Mac，明确缓）
- 通用远控（UU 已做好，不碰）
- 服务器按键转发（2026-08-05 定案删除）
- 宏的变量/分支（轻量复合指令定位，超界用 AHK）
- 开机自启（控制台/面板按需启动，桌面快捷方式）
